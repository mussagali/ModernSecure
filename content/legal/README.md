# Поддержка и удаление аккаунта

`documents.ru.json` содержит реквизиты для `/support` и текст `/deletion-policy`. Поля terms/privacy в этом файле — исторические заготовки; опубликованные `/terms` и `/privacy` читаются из `legal_documents` в Supabase. Не заменять действующие редакции этими заготовками.

Миграция `20261114010400_account_deletion_requests.sql` добавляет собственный запрос и очередь главного администратора. Перед развёртыванием страниц применить только новую миграцию к существующей базе; полный `supabase-upload/01_INSTALL_SCHEMA.sql` предназначен для пустой базы.

Запрос доступен авторизованному владельцу до активации и прохождения MFA. Это узкое исключение для собственных данных, не доступ к делам. Повторная отправка возвращает открытый запрос. Завершение блокируется, пока Auth-аккаунт существует.

Срок до 30 календарных дней соответствует действующим опубликованным соглашениям. Обработка ручная: оператор удаляет не подлежащие обязательному хранению данные и файлы, фиксирует основания/сроки исключений, отзывает доступ и отправляет подтверждение заявителю. Только после фактического исполнения ставит «Завершено». Существующая функция удаления Auth-аккаунта сохраняет деловые записи и сама по себе не означает полного исполнения запроса о персональных данных. Автоматическая отправка подтверждения не реализована.

Тесты используют изолированную PGlite. Реальные пользовательские данные в ходе подготовки не удалялись. Релизный статус и оставшиеся проверки: `apps/mobile_webview/ios/app-store/RELEASE-STATUS.ru.md`.
