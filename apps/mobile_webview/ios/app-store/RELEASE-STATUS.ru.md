Приложение: ModernSecure — Защита, Apple ID **6824547106**, Bundle ID **kz.modernsecure.modernSecure**, команда **HRXCR95QG3**. Пользователь подтвердил ссылку существующего приложения. Готовится **1.0.1 (4)**; номер проверяется read-only Apple API перед подписанием. Отправка на App Review и выпуск не запускаются сборкой.

## Изменения

- Объединены текущий веб-дизайн и ранее проверенные инструменты ветки `release/app-store-preparation` (6ff5452).
- Release использует `https://modern-secure.vercel.app`; старый домен не используется приложением.
- Иконка 1024 × 1024 без прозрачности собрана из существующего бирюзового логотипа. Исходный логотип сайта — PNG 200 × 200: для более чёткой иконки на больших размерах желателен фирменный вектор; рисунок не менялся.
- Нативный экран ошибки использует тот же знак и цвета. WKWebView ограничен верхней границей клавиатуры; чат не должен скрывать композер под ней. Требуется проверка на реальном устройстве.
- Privacy manifest покрывает данные аккаунта, документов, платежей и аудита; tracking=false, UserDefaults reason CA92.1. Firebase не настроен, push не заявлен рабочим.
- Добавлены `/support`, `/delete-account`, `/deletion-policy` и очередь главного администратора. Срок до 30 дней взят из уже опубликованной политики, а не придуман для релиза. Запрос доступен до активации, при ограниченном доступе и без повторного принятия соглашения. Завершение невозможно, пока Auth-аккаунт существует.
- Удаление аккаунта и очистка всех персональных материалов — разные действия: оператор обязан обработать не требующие хранения данные, документировать исключения и отправить подтверждение до отметки «Завершено». Действующая функция удаления аккаунта сохраняет деловые документы; она одна не заменяет исполнение запроса о персональных данных.

## Проверки

- Веб: 52/52 локальных сценария, ESLint и production build прошли.
- iOS: локальная проверка исходников, 21 тест инструментов и Swift syntax parse прошли. Полного Xcode на этом Mac нет, компиляция проверяется на GitHub macOS.
- Первая simulator-сборка выявила несовместимый с Firebase 13 вызов `deleteToken(completion: nil)`; исправлен обработчиком завершения.

## Перед отправкой в App Review

1. Проверить итоговую сборку в TestFlight на физическом iPhone и iPad: вход/выход, регистрация, восстановление, клавиатура чата, камера/файлы/Quick Look и возвращение из внешних ссылок.
2. Проверить действующий серверный ключ Supabase: ранее файловые операции были заблокированы `Unregistered API key`. Сборка iOS этого не исправляет; без настоящего теста файлов нельзя отмечать проверку пройденной.
3. Сверить в App Store Connect текущую опубликованную версию, выбрать новую сборку, обновить Privacy URL, Support URL, скриншоты и заметки. Старые скриншоты относятся к прежнему дизайну и не подтверждают этот релиз.
4. Проверить демо-аккаунт ревьюера после новой версии соглашений. Его пароль вводится только в закрытые поля Apple; не в Git и не в общедоступные артефакты.
5. Владелец проверяет актуальность соглашений Apple и анкеты данных/возраста. Старое одобрение не заменяет проверку новой версии.
6. Режим выпуска — вручную. Наличие IPA не означает, что приложение одобрено или опубликовано.
